# PFFc
Este trabalho visa disponibilizar à comunidade uma ferramenta computacional para calcular as capacidades resistentes de perfis formados a frio (seções U, U enrijecido e cartola) submetidos à esforços de compressão uniforme, tração, cortante e flexão em torno de um dos eixos principais de inércia, bem como a combinação desses esforços.
